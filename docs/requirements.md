# PromptKeep 要件定義（Flet）

## 1. 目的
- プロンプトをローカルで安全に管理・閲覧・編集・コピーするシンプルなデスクトップアプリを提供する。
- 階層カテゴリとお気に入りで整理し、カード表示で素早く参照できることを重視。

## 2. スコープ
- Flet を用いたデスクトップアプリ（ダークテーマ固定）。
- ローカル JSON ファイルへの永続化。クラウド連携やインポート/エクスポートは対象外。
- シングルユーザー前提。マルチユーザーや認証は対象外。

## 3. 想定ユーザー / ユースケース
- プロンプトを日常的に作成・整理する個人ユーザー。
- よく使うプロンプトをカードで素早くコピーし、必要に応じて編集する。
- カテゴリ階層（最大 3 階層）で整理し、お気に入りで横断的に参照する。

## 4. データモデル（ローカル JSON）
- `prompts.json` に保存。
- スキーマ（例）
  ```json
  {
    "prompts": [
      {
        "id": "uuid",
        "title": "string",
        "body": "string",
        "category_path": ["root", "child", "grandchild"],
        "favorite": false,
        "deleted_at": null,
        "created_at": "ISO8601",
        "updated_at": "ISO8601"
      }
    ],
    "categories": [
      { "id": "uuid", "name": "string", "parent_id": null }
    ],
    "trash": {
      "prompts": ["prompt_id", ...],
      "categories": ["category_id", ...]
    }
  }
  ```
- 制約
  - カテゴリ階層は最大 3 階層。
  - `category_path` はルートからの配列。未分類は `[]`。

## 5. 機能要件
- 一覧/カード
  - 右ペインにカードグリッド表示（タイトル、本文先頭プレビュー 40〜80 文字、省略記号…）。
  - カードは正方形デザイン。画面幅に応じてレスポンシブに列数を調整。
  - カード右上にコピーアイコン。クリックで本文全文をクリップボードへ。右下に控えめなトースト表示。
  - カード上にお気に入り★トグル。
- プロンプトの CRUD
  - 追加ボタンで空カードを生成し、カードクリックで右ペイン編集ビュー表示（タイトル/本文編集）。
  - 既存カードクリックで同じ編集ビューを再利用。
  - 編集中は自動保存（リアルタイムまたは数秒のデバウンス）。保存ボタンなしでも内容を保持。
  - 削除は即時反映（確認ダイアログなし）＋右下にメッセージ。削除アイテムはゴミ箱へ移動。
  - 「Ctrl+Z」で直前の削除をアンドゥ。ゴミ箱からの復元も可。
  - ゴミ箱は無期限保持。ゴミ箱を空にする操作で完全削除。
- カテゴリ
  - 左サイドバー上部：検索、カテゴリフィルタ UI（優先度低）。
  - 左サイドバー下部：「＋」でカテゴリ追加ダイアログ。
  - カテゴリはドラッグ&ドロップで並べ替え/親子付け（最大深さ 3）。
  - カテゴリ選択で右ペインのカードをフィルタ。
- お気に入り
  - カード上の★でトグル。お気に入りビュー/フィルタを提供（左サイドバーまたは上部フィルタ）。
- 検索・フィルタ（低優先）
  - タイトル＋本文全文検索。カテゴリフィルタとの AND で絞り込み。
- UI/UX
  - ダークテーマのみ。シンプルな配色と余白、カード表示。
  - 右ペインに編集フォーム。閉じる/戻るボタンで一覧へ戻る。
  - コピー/削除/復元/保存にスナックバー等で控えめなフィードバック。

## 6. 非機能要件
- ローカルのみで動作し、ネットワーク不要。
- JSON 読み書きはアトミックに行い、書き込み失敗時はロールバック（テンポラリファイル経由）。
- 起動時に JSON を読み込み、書き込み後は即フラッシュ。
- パフォーマンス: 1,000 件程度のカードで快適にスクロールできること。
- アクセシビリティ: キーボード操作（Tab、Enter、Ctrl+C、Ctrl+Z）とコントラスト確保。

## 7. 画面/コンポーネント要件
- メイン画面
  - 左サイドバー：検索ボックス、カテゴリフィルタ、カテゴリツリー（D&D で並べ替え/階層化）、カテゴリ追加ボタン。
  - 右ペイン：カードグリッド（正方形カード、レスポンシブ列数）、プロンプト追加ボタン。
- 編集ビュー（右ペイン内で切り替え）
  - フィールド: タイトル、本文テキストエリア、カテゴリ選択（ツリー/ドロップダウン）。
  - 自動保存（入力後数秒のデバウンス）。保存ボタンは補助的に設置可。
  - 操作: キャンセル/戻る（警告なし、自動保存済み前提）。
- ゴミ箱ビュー（モーダルまたはサイドバー項目）
  - 削除済みカード一覧（無期限保持）、復元ボタン、ゴミ箱を空にするボタン。

## 8. 状態管理 / 振る舞い
- ローカル状態: メモリ上のリスト＋ JSON 永続化。
- アンドゥ: 直近操作（削除）を 1 ステップ戻す。スタック保持は 1 件で十分。
- ドラッグ&ドロップ: カテゴリの親子変更時に深さを検証し、3 超えは拒否＋メッセージ。
- お気に入り/コピー/削除/復元/保存はスナックバーで結果通知。

## 9. エラーハンドリング
- JSON 読み込み失敗時: バックアップからのリカバリまたは空データで起動し、ユーザーに通知。
- 書き込み失敗時: 変更をロールバックし、エラー通知。
- D&D 深さ制限超過: 操作をキャンセルし、理由を提示。

## 10. 優先度
- Must: カード表示、追加/編集/削除、コピー、カテゴリ（追加・選択）、お気に入り、JSON 永続化、アンドゥ（削除）、ゴミ箱、ダークテーマ。
- Should: カテゴリ D&D（最大 3 階層）、検索/フィルタ、ゴミ箱を空にする UI。
- Could: スクロール時の仮想化、カードレイアウトレスポンシブ調整。

## 11. 開発メモ
- Flet コンポーネント想定: `Page`（ダークテーマ設定）、`Column`/`Row`/`GridView`、`Draggable`/`DragTarget`（カテゴリ D&D）、`ListView`、`TextField`、`IconButton`、`SnackBar`。
- ファイルパス: `data/prompts.json`（初期は空を生成）。
- ID 生成: `uuid4`。
- 本文プレビュー: 先頭 40〜80 文字＋省略記号。
- カード形状: 正方形（width = height）、レスポンシブで列数を調整。
- 自動保存: テキスト入力から 2〜3 秒のデバウンスで JSON へ自動保存。

## 12. 確定済み仕様
- 本文プレビュー文字数: 40〜80 文字
- カード形状: 正方形、画面幅レスポンシブ
- 検索対象: タイトル＋本文全体
- 編集ビュー: 自動保存（警告なし）
- ゴミ箱: 無期限保持
